# CaseLens — Bilingual (EN/FA) Enterprise SaaS Dashboard

Part of the `frontend-portfolios` monorepo. Next.js 14 App Router, no external fonts/CDN scripts, deploys to Vercel as-is.

## Pages
- `/en` / `/fa` — Dashboard (KPI cards + recent high-priority anomalies)
- Cases with live filtering, status badges, risk scores
- API Keys with token masking, scopes, status badges
- Settings workspace form

RTL is enabled automatically for the `fa` locale.
